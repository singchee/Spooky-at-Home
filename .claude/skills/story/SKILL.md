# /story — the writer

1. Launch the `story-writer` subagent with the request.
2. Check that every factual line is pinned to mission data by a test (intel is always true), and that no line jokes about real places, people or schools.
3. Voice lines go to `/sound` for generation within budget. New narrative features (campaigns, characters) are class C, so propose them to the owner.
